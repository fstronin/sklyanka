# Оснастка спайка SKL-03

Стенд не живёт в приложении: измеряется **продуктовая отладочная сборка**, а здесь —
только то, что готовит нагрузку, снимает журнал и считает числа. Выбор инструмента
и его обоснование — `docs/tasks/SKL-03/tech-options.md`; устройство стенда —
`docs/tasks/SKL-03/TDD.md`; порядок прогона для заказчика — `docs/tasks/SKL-03/runbook.md`.

| Файл | Роль |
|---|---|
| `gate.py` | формальный стенд: расчёт гейта НАП-3 (доля вовремя, отклонения, перерывы, тихие отказы, разбивка по сценариям); `results.json` + `summary.txt` |
| `collect.sh` | снять журнал (выгруженный CSV или копия базы по adb) и запустить расчёт стенда |
| `mark.sh` | отметить начало и конец сценария И-1 … И-16 по часам устройства |
| `personal.py` | личный пилот: расчёт по CSV без синтетической сетки (классы приёмов, перерывы, восстановленные пропуски регулярных серий, выбросы); `results.json` + `summary.txt` |
| `personal-sample.csv` | образец выгрузки для самопроверки `personal.py` |
| `test_personal.py` | самопроверка `personal.py` на образце, с посчитанными вручную числами |

```bash
# Расчёт по CSV, выгруженному приложением (основной путь заказчика)
./collect.sh --csv ~/Downloads/sklyanka-reminder-journal-2026-10-15.csv \
    --platform "Huawei …, EMUI 15.0, Android 14" --out build/spike

# Резервный путь: снять копию базы с подключённого устройства (отладочная сборка)
./collect.sh --serial FMR0219A30001234 --out build/spike

# Отметки сценариев во время коротких заходов
./mark.sh И-1 начало
./mark.sh И-1 конец

# Личный пилот (решение 30.09.2026): расчёт по недельной выгрузке журнала
python3 personal.py --csv ~/Downloads/sklyanka-reminder-journal-2026-10-08.csv \
    --zone Europe/Moscow --platform "Pura 80 Ultra, EMUI 15.0.x, AOSP 12" --out-dir build/personal

# Самопроверка personal.py на образце (числа закреплены в тесте)
python3 test_personal.py
```

`gate.py` читает только идентификаторы, моменты и служебные коды: медицинских данных
в журнале нет ни в одной колонке (НФТ-19). Гейт скрипт не объявляет: он называет числа,
порог 95 % и условия решения, а решение принимает человек (14 суток непрерывно
на настроенном эталоне).
