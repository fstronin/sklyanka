# ADR-0005. Шаблон уведомления Wear Engine вместо приложения на часах

## Статус

Принято. 26 сентября 2026.

## Контекст

`design/SPEC-original.md §6` описывает целевой сценарий: напоминание уходит на часы
карточкой «Принято / Пропустить», нажатие возвращается в колбэк на телефоне, приём
отмечается. Третья кнопка «Отложить» по умолчанию выключена — на круглом экране тесно.

Обстоятельства, определяющие решение:

1. **HUAWEI Watch GT 6 Pro — lite wearable.** Собственное приложение на часах нужно только
   для интерфейса сложнее шаблона. Разработка под lite wearable — отдельный инструментарий,
   отдельная сборка, отдельная публикация.
2. **Права индивидуального разработчика ограничены.** В AppGallery Connect индивидуальному
   аккаунту доступны только базовые права Wear Engine: информация об устройстве и
   сообщения/уведомления. Права на здоровье и сенсоры — для корпоративных аккаунтов.
3. **Ревью заявки ручное**, ориентировочно 1–2 недели, с привязкой SHA-256 подписи. Поэтому
   заявка (SKL-01) подаётся в первый день и идёт параллельно разработке.
4. **Право `NOTIFY`** выдаётся по умолчанию начиная с Huawei Health 11.0.3.512.
5. **Имя пакета не длиннее 28 символов** для шаблонных уведомлений. `ru.heuri.sklyanka` —
   17 символов, запас есть.
6. **Health Kit для приёма лекарств бесполезен**: его типы данных — активность, состав
   тела, сон.

Шаблон `NotificationTemplate` поддерживает ноль, одну, две или три кнопки; отправка через
`HiWear.getNotifyClient()`, подписи задаются `setButtonContents()`, нажатие возвращается
в `Action.onResult(notification, feedback)` на телефоне. Ровно то, что нужно сценарию.

## Решение

Карточка на часах собирается шаблоном уведомления Wear Engine с двумя кнопками. Приложения
на часах нет.

Заголовок карточки — до примерно 20 символов, текст — название и доза одной строкой
(`§6`). Отметка, пришедшая с часов, обрабатывается тем же кодом, что и отметка с телефона,
и идемпотентна по `intake_id`: при двойной отметке выигрывает первая по `acted_at` (`§3`,
`НФТ-10`).

Если Wear Engine недоступен, приём отмечается в телефоне. Приложение полноценно работает
без часов: отсутствие Wear Engine не блокирует ни один сценарий, кроме отметки с часов.

## Последствия

- Объём работы по часам сводится к отправке шаблона, обработке колбэка и экрану подключения
  с цепочкой проверок (SKL-16, SKL-17). Это вписывается в один этап вместо отдельной ветки
  разработки.
- Оформление карточки задаёт система часов. Приложение управляет только текстом и подписями
  кнопок; цвета `#0C0C0D`, `#2A2724`, `#272423` из макета `design/screens/Watch.dc.html` —
  изображение устройства, а не токены приложения (`08-design-system.md §1.2`).
- Ограничение «до ~20 символов в заголовке» становится требованием к текстам: длинные
  названия лекарств придётся сокращать, и правило сокращения нужно задать явно.
- Третья кнопка «Отложить» остаётся выключенной по умолчанию. Включение — вопрос настройки,
  а не архитектуры.
- Часы — отделяемая функция. Задержка или отказ в правах Wear Engine не блокируют выпуск:
  этап 7 отваливается целиком, продукт остаётся работоспособным (`PLAN.md §5`).
- Появляется зависимость от версии Huawei Health на телефоне и от прошивки часов; поведение
  при несоответствии не зафиксировано → `ОВ-19`.
- Обычное зеркалирование уведомлений Android на GT-серию даёт только текст, без кнопок —
  то есть без Wear Engine сценарий «отметить с часов» не деградирует, а исчезает.

## Альтернативы

**Собственное приложение на часах.** Свой интерфейс, свои данные на часах, отметка без
телефона рядом. Отвергнуто: GT 6 Pro — lite wearable, разработка ведётся отдельным
инструментарием, публикуется отдельно и даёт интерфейс, который шаблон на две кнопки уже
покрывает. Сценарий приложения — «нажать одну из двух кнопок», а не «вести учёт на
запястье».

**Health Kit.** Штатный путь для медицинских данных Huawei. Отвергнут: типы данных Health
Kit — активность, состав тела, сон; приёма лекарств среди них нет. Кроме того, права на
здоровье недоступны индивидуальному аккаунту.

**Зеркалирование системных уведомлений без Wear Engine.** Ничего не требует: уведомление
телефона показывается на часах само. Отвергнуто как основной механизм: на GT-серии
приходит только текст, без кнопок, а значит отметить приём с часов нельзя — теряется весь
смысл интеграции. Остаётся как естественный запасной вариант, когда Wear Engine недоступен.
