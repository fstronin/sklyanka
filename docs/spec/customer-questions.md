# Вопросы заказчику

> **Требуется сессия с заказчиком.** Эти вопросы не решаются разработкой или дизайном
> молча — по каждому нужно слово заказчика. Всё остальное уже закрыто: зона разработки
> решена, зона дизайна решена (см. `12-open-questions.md` и `design-answers.html`).
> Если вопроса нет в этом файле — решение принято, заказчик к нему не привлекается.
>
> Для вопросов «Заказчик + разработка» техническая часть уже сделана — заказчик
> подтверждает только поведение. Для «Заказчик + дизайн» дизайн-часть встанет в работу
> после решения заказчика.

## Итог сессии (30.09.2026)

Сессия с заказчиком закрыла перечисленные в этом файле вопросы; таблицы ниже остаются
историей. Кратко:

- **ОВ-1** — поиск обозначения не проводить.
- **ОВ-2** — страница продукта на `stohastika.ru`.
- **ОВ-5** — продукт для магазина.
- **ОВ-20** — индивидуальный аккаунт; аккаунты AppGallery и RuStore у заказчика есть.
- **ОВ-21** — менеджер секретов; keystore создать до SKL-22.
- **ОВ-26** — решение по непройденному гейту принимает ведущая сессия.
- **ОВ-71** — категория «Здоровье и фитнес».
- **Часы** — правила зафиксированы (Huawei Health `11.0.3.512`; `acted_at` = время нажатия,
  иначе время колбэка; порог «в сети» — в SKL-17), факты проверяются на устройстве
  в SKL-16/17 (пост-MVP).
- **Устройство** — эталонный Huawei с EMUI 15 есть, ставится на 14 суток (SKL-03).
- **Аккаунты** — AppGallery и RuStore у заказчика есть.

Продуктовые подтверждения сессии (ОВ-8, ОВ-34, ОВ-36, ОВ-43, ОВ-58, ОВ-69) —
в `docs/spec/12-open-questions.md`.
