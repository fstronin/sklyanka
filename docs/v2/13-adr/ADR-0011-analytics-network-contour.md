# ADR-0011. Аналитический сетевой контур во всех сборках

## Статус

Снят решением Р-4 (07.10.2026): клиентская аналитика и A/B-эксперименты вырезаны из продукта.

## Решение

Не действует. Аналитического контура в продукте нет: ни сбора событий, ни согласия
на аналитику, ни A/B-экспериментов, ни вендора (`docs/v2/00-product.md` §5.3, §6).
Единственный сетевой контур продукта — платный (`ADR-0010`).

## Основание

Вендора не существует: HUAWEI Analytics закрыт для новых проектов (30.06.2024), A/B Testing
снят из AppGallery Connect глобально (15.0.1, 27.03.2025). Ни одного события не собиралось,
реализация была отдана заглушке `NoOpAnalytics`, а мёртвый контур стоил сопровождения
и путал состав сборки (Р-4).

## Следствия

- Удаляются: порт `Analytics` и `AnalyticsSink`, `NoOpAnalytics`, каталог из 16 событий,
  гейт `ConsentedAnalytics`, хранилище согласия `sklyanka_analytics_consent`, модуль
  `core-analytics`, экран согласия, строка «Аналитика» в настройках, зарезервированные
  события воронки подписки (Р-4, `docs/v2/04-roadmap.md` фаза 0).
- Признаки успеха измеряются без клиентской аналитики: журнал срабатываний и ручной прогон
  для У-1…У-5, серверные счётчики и консоли магазинов для У-6…У-9 (`docs/v2/00-product.md` §8).
- Воронка платной подписки клиентской аналитикой не измеряется вовсе
  (`docs/v2/03-monetization.md` §7).
- `INTERNET` в манифесте отсутствует и запрещён гейтом
  (`build-logic/.../AnalyticsContourRules.kt:46-51`); белый список координат пуст.
  Разрешение возвращается только вместе с платным контуром (`ADR-0010`, ИИ-24).
- Отчёт разработчику отдельным контуром не сохраняется: заглушка, отвечавшая «отправлено»
  без отправки, удаляется вместе с кнопкой (П-7); функция возможна только с реальной
  отправкой (Р-1, задача SKL-103).
- Возврат аналитики возможен только новым решением Р-N с названным провайдером, политикой,
  согласием и уведомлением Роскомнадзора (Р-4).

## Пересмотры
