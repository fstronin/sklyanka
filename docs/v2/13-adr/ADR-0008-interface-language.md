# ADR-0008. Язык интерфейса закреплён за приложением

## Статус

Действует.

## Решение

**Язык текста принадлежит приложению, формат времени — человеку.**

1. Объявлено шесть языков: `ru` (базовый и запасной), `en-US`, `es`, `de`, `zh-CN`, `kk` (Р-2).
   Состав согласован в трёх местах: манифест (`app/src/main/res/xml/locales_config.xml`,
   `android:localeConfig`), сборка (`ProjectDefaults.INTERFACE_LOCALES` →
   `resourceConfigurations`), код (`InterfaceLocale.SUPPORTED`). Совпадение трёх составов
   проверяется guard-тестом
   (`acceptance/src/test/kotlin/ru/stohastika/sklyanka/acceptance/localization/LocalizationResourcesTest.kt`).
2. Язык выбирает приложение, а не телефон: контекст приложения и каждой активности
   оборачивается в `attachBaseContext` локалью из `InterfaceLocale.resolve(deviceLocales)` —
   побеждает первый язык устройства, у которого есть объявленный «родственник»; поиск идёт
   по языку, а не по стране (`en-GB` находит `en-US`, `zh-TW` — `zh-CN`). Объявленного языка
   нет — берётся `FALLBACK = ru` целиком: русские склонения и форматы приходят вместе
   с русскими строками.
3. Базовый набор ресурсов русский (`values/`), `values-ru` нет; переводы —
   `values-{de,en-rUS,es,kk,zh-rCN}` в `app` и `core-ui`. Свойство закреплено guard-тестом.
4. Предпочтение 12- или 24-часового времени читается из системной настройки
   (`DateFormat.is24HourFormat`): это настройка человека, а не свойство языка.
5. Слой хранения и файл переноса форматируют нейтральной локалью (`Locale.ROOT`): машинное
   значение не зависит от языка телефона ни в какую сторону (`ADR-0013`).
6. Внутриприложенческого переключателя языка нет; `LocaleManager` (API 33+) не используется —
   `minSdk 26` (ПЛ-1).

## Основание

Форму множественного числа выбирает локаль конфигурации ресурсов, а не язык строки: приложение
с русскими строками на устройстве с локалью `en-US` печатало «15 минуты» и «27 September».
Обёртывание контекста в одной точке входа лечит строки, склонения и слова внутри дат разом,
а забытая точка проявилась бы только на чужом устройстве — там, где её никто не увидит.

## Следствия

- Все пять активностей проходят через `withInterfaceLocale()`; контексты уведомлений,
  PDF-отчёта врачу и имени профиля по умолчанию получают то же обёртывание. Активность,
  добавленная мимо этой точки, проверяется шагом приёмки, а не дисциплиной.
- Полнота переводов, формы множественного числа, плейсхолдеры и отсутствие русского текста
  в чужих переводах проверяются guard-тестом (НФТ-43, НФТ-43а).
- Локализационная матрица шести языков — обязательная часть приёмки любого экранного
  изменения, а не разовая задача (Р-2).
- Экранные проверки идут с локалью устройства, отличной от русской: прогон не слеп
  к этому классу дефектов.
