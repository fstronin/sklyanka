## 2. Журналы и номера

- Решения продукта: прежние ПМ-N не переиспользуются и не переносятся; действующие — Р-N
  (`docs/v2/02-decisions.md`). Ссылки из кода и старых документов на ПМ-N читаются как история.
- Открытые вопросы: ОВ-N закрыты решениями, записями Р-N или находками V-N; живые вопросы
  без номеров ОВ ведутся в `PLAN.md` §5.
- Задачи: сквозная нумерация SKL-NN продолжается с 105; снятые задачи помечены в реестре
  `PLAN.md` §4 номером решения.

## 3. Приёмочные сценарии

`*.feature` читаются модулем `acceptance` из `docs/tasks/SKL-NN/` до переезда (SKL-111):
путь по умолчанию меняется на ресурсы модуля, сценарии снятых задач (ЧАС-*, аналитика)
удаляются вместе с функциями (SKL-106), сценарии закрытых задач остаются регрессией.

## 4. Что не переезжает

Требования без метода проверки в нормативный слой не попадают (правило слоя v2):
прежние НФТ- без метода либо получают метод в `11-quality.md`, либо снимаются записью Р-N.
